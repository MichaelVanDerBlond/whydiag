# TASK-0001

## Название
Добавление проверки корневого файлового системного пространства

## Цель
Добавить новую диагностическую проверку для анализа состояния корневой файловой системы. Эта проверка должна проверять, является ли файловая система корня доступной только для чтения и использует ли она более 85% своего пространства.

## Контекст
Эта задача связана с существующими компонентами проекта, такими как inventory для сбора данных и core для управления выполнением проверок. Проверка будет добавлена в раздел linux checks.

## Требования
1. Создать новую диагностическую проверку `FilesystemCheck` в пакете `linux`.
2. Проверка должна возвращать состояние `ERROR`, если файловая система корня доступна только для чтения или использует более 85% своего пространства.
3. В случае успешного выполнения проверки, возвращать состояние `OK` с информацией о количестве использованного и доступного пространства в ГБ.
4. Добавить тест для новой проверки, который будет проверять корневую файловую систему на наличие проблем.

## Ограничения
1. Не изменять существующие функции или данные в inventory.
2. Проверка не должна менять конфигурацию сервера.
3. Проверка не должна исправлять систему автоматически без отдельного режима.

## Тестирование
1. Создать тест, который проверяет корневую файловую систему на доступность только для чтения и использование более 85% пространства.
2. Убедиться, что тест правильно обрабатывает ошибки и возвращает соответствующее состояние.
3. Проверить, что проверка корневой файловой системы не нарушает работу других частей проекта.

## Критерии приёмки
1. Проверка должна быть добавлена в проект и успешно выполняться без ошибок.
2. Состояние проверки должно корректно отражать состояние файловой системы (OK, WARNING, ERROR).
3. Тест для проверки должен быть добавлен и проходить успешно.
4. Проверка не должна влиять на другие части проекта или нарушать его работу.

После выполнения задачи Developer предоставит изменения в исходный код, тесты и документацию, которые будут проверены Architect для обеспечения соответствия требованиям и целостности проекта.
